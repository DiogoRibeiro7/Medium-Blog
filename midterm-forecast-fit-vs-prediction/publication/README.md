# Scientific publication assets

The 2026 pre-election editorial manuscript and Medium-ready copy are archived in the private `DiogoRibeiro7/research-articles-medium` repository. The public project retains the fifteen [equation PNGs](equations/), [scientific figures](../figures/), [forecast lock](../PRE_ELECTION_REGISTRATION.md), and [reproducible code](../analysis.py).

The `prepare_medium_publication.py` script remains for historical reproducibility, but its editorial build/check commands require the privately archived source and are not part of public CI. Public CI validates equation artwork and recomputes the scientific outputs without private manuscripts.
