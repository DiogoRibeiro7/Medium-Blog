# Sequential Detection Is Not a Decision Rule

The full-length 10-page LaTeX manuscript supersedes the earlier short draft.
It uses the completed, preregistered Monte Carlo study, with transparent
distinction between the confirmatory primary comparison and post-hoc descriptive
analysis of existing archived evaluation rows.

Compile locally in this folder with:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The figure uses `cumulative-difference.csv`, computed from the archived
gradual-drift evaluation data; it is not a new experiment.
Numerical results trace to [GitHub Actions run #40089779139](https://github.com/DiogoRibeiro7/Medium-Blog/actions/runs/40089779139).
The full workflow artifact is time-limited. The compact, checked-in evidence
record is at `../results/2026-10-24-detector-evidence/`.

This is a research manuscript under development and is not peer reviewed.
