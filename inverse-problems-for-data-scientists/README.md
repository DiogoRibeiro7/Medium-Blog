# A Good Fit Is Not an Identified Model

Reproducible research companion to
[the full Medium manuscript](article.md), *A Good Fit Is Not an Identified
Model: Inverse Problems for Data Scientists*.

The study is wholly **synthetic**. It uses a 64-dimensional latent signal, a
known full-rank but ill-conditioned diffusion-like spectral smoothing operator,
and independent Gaussian observation noise with known standard deviation.
This operator is dimensionless: it is not a calibrated model of a real heat,
medical-imaging, geological, or industrial instrument.

## The scientific questions

1. Can two distinct latent signals yield identical observations? Yes when the
   20-row sparse sensor matrix has a 44-dimensional exact null space.
2. Can a full-rank matrix fit the observed data perfectly while failing to
   reconstruct the signal? Yes when its small singular values amplify noise.
3. How do truncated SVD and Tikhonov regularization change reconstruction
   accuracy and observed-data residuals?
4. Does generalized cross-validation (GCV) select the same penalty as a
   latent-truth oracle? Not in general; the objectives differ.
5. Are Bayesian 95% pointwise credible intervals automatically 95%
   frequentist confidence intervals for a fixed latent truth? No.
6. How does spatial sensor placement affect uncertainty with a constant
   measurement budget? Compare clustered, space-filling, and greedy A-optimal
   designs, with paired noise across repeated synthetic trials.

The numerical comparison evaluates different estimands: structural
identifiability, latent reconstruction error, prediction error, posterior
uncertainty, and fixed-truth repeated-noise coverage. A low residual against
the observed vector is not treated as evidence for unique parameter recovery.

## Reproduce

From this directory:

```bash
python -m pip install -r requirements.txt
python analysis.py
python -m unittest discover -s tests -v
```

For a faster end-to-end check with fewer Monte Carlo replicates:

```bash
python analysis.py --quick
```

The full study uses 480 noise replicates per repeated-noise experiment; quick
mode uses 64. Both modes use seed `20261030`, with independent named random
number streams so the single observed signal does not change with the trial
count. Quick figures and tables have `_quick` filename suffixes, keeping full
publication results untouched.

The executable [notebook](inverse_problems.ipynb) walks through the main
constructions and can be rerun in a fresh kernel. The scoped GitHub Actions
workflow installs the pinned study dependencies, runs the mathematical tests
and executes the quick reproduction. No other article's expensive experiments
are required.

The `results/` folder holds ten full study CSVs:

| `bayesian_intervals.csv` | Pointwise posterior means, SDs, nominal intervals and repeated-noise fixed-truth coverage |
| `sensor_designs.csv` | Sensor selection order and coordinate for each of three budget-matched designs |
| `design_budget.csv` | Posterior covariance trace as each design adds sensors |
| `monte_carlo_methods.csv` | Replicate-level latent recovery errors for three frequentist inverse estimators |

The result exports are intentionally small. All random draws and analytical
parameters can be reconstructed from the versioned script.

## Key assumptions and limitations

- The forward map, grid, observation-noise distribution, and SD are **known by
  construction**. Real inverse problems may include error in the operator.
- The full map is square and technically invertible in exact arithmetic; the
  20-sensor map has an actual nullspace. These are not equivalent claims.
- Singular values are imposed by a DCT spectral model. Their decay represents
  smoothing but is not evidence for any instrument.
- The displayed oracle reconstruction error uses synthetic latent truth and
  is unavailable when reconstructing an unobserved physical signal.
- The Gaussian Bayesian prior is deliberately smoother than parts of the
  constructed truth. Posterior intervals are conditional on that prior and
  likelihood. Coverage fixes the truth and repeats **noise**, not draws from
  the prior.
- The greedy A-optimal selection is a local, one-step covariance-trace
  heuristic, not a proved global optimum; trace depends on the specified
  prior, candidate sensor locations and assumed noise.
- All 20-sensor designs have the same measurement budget and use common
  underlying full-grid noise draws for paired comparisons; no financial
  deployment cost or sensor failure mechanism is modelled.
- The study does not address nonlinear/non-Gaussian inversion, spatially
  correlated noise, forward-model discrepancy, nonstationarity, missing
  sensors or out-of-distribution deployment.
