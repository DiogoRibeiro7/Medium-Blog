2. Separation of duties: residual error after k reviewers
==============================================================================
Model: item difficulty U ~ N(0,1). Agent j errs on an item when lam_j*U + sqrt(1-lam_j^2)*Z_j > tau_j,
Z_j independent N(0,1); tau_j = Phi^-1(1 - q_j). Two agents' errors then have tetrachoric correlation lam_j*lam_k.
A reviewer stops a producer's error only if it would itself answer correctly AND it is not anchored on the
producer's answer (anchoring probability a). Residual error after k reviewers:
   R_k = E_U[ p_P(U) * prod_j ( a + (1 - a) p_j(U) ) ],  p_j(U) = Phi((lam_j U - tau_j) / sqrt(1 - lam_j^2))

Producer and reviewers all err on 20% of items (same model, same role prompt quality).

3. Deliberation: a lead and four advisers on four-option questions
==============================================================================
Agents err with probability 0.3 (error correlation rho = 0.5); an erring agent picks the item's most
attractive wrong option with probability g = 0.632, so two erring agents agree 60% of the time.
Each round, every agent sees the others' current answers. With probability c it is persuaded by evidence:
if it is wrong and someone holds the right answer, it switches to it. Otherwise, with probability s it conforms:
it adopts the answer with the most weight among the others (the lead counts w, advisers 1; it keeps its own
answer if that answer ties for the most weight). Otherwise it keeps its answer. Three rounds. Option 0 is correct.

4. The last human: one reviewer, a fixed budget, a growing team
==============================================================================
Human reads 238 words/min for 120 min/day -> 28,560 words/day.
Each agent hands over 4 deliverables of 1,000 words a day; each pair of agents adds 150 words of coordination the human must read (Graicunas/Brooks: pairs grow as n(n-1)/2).
A deliverable carries a material error with probability 0.15; read in full, an error is caught with probability 0.8; read in part, in proportion to the share read. A caught error costs the deliverable;
an uncaught one costs D (in units of a correct deliverable's value V = 1).
  D = 2   best team size 20 (net value 49.05/day); net value at n=12: 32.08; first n with negative net value: none up to 20
  D = 5   best team size 20 (net value 20.63/day); net value at n=12: 19.01; first n with negative net value: none up to 20
  D = 10  best team size  6 (net value 13.20/day); net value at n=12: -2.79; first n with negative net value: 12
  D = 20  best team size  6 (net value 6.00/day); net value at n=12: -46.38; first n with negative net value: 8
  share of output the human can read: n=1: 100%, n=2: 100%, n=4: 100%, n=8: 79%, n=12: 49%
  words produced per day (work 'done'): n=1: 4,000, n=4: 16,900, n=12: 57,900
  D = 2   slope per extra agent once reading is saturated (no coordination): +2.20; break-even D = (1-e)/e = 5.67
  D = 5   slope per extra agent once reading is saturated (no coordination): +0.40; break-even D = (1-e)/e = 5.67
  D = 10  slope per extra agent once reading is saturated (no coordination): -2.60; break-even D = (1-e)/e = 5.67
  D = 20  slope per extra agent once reading is saturated (no coordination): -8.60; break-even D = (1-e)/e = 5.67
Sensitivity: best team size by daily reading budget (D = 10)
   30 min/day -> best n = 2, net value 3.21
   60 min/day -> best n = 3, net value 6.60
  120 min/day -> best n = 6, net value 13.20
  240 min/day -> best n = 12, net value 25.62
  480 min/day -> best n = 20, net value 44.00
