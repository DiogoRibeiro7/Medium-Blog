== 5. Three runs and a bootstrap ==
a percentile bootstrap over three runs: the 2.5% point is the smallest run, because all three resamples
  equal the smallest with chance 1/27 = 0.037 > 0.025, so the 95% interval is the range of the three runs,
  which holds a symmetric quantity's centre with chance 1 - 2(1/2)^3 = 0.75
  the honest t multiplier with three runs is 4.30, not 1.96
simulation: 18 tau2 comparisons x 300 replicates, three runs per task per model
one model's mean, percentile bootstrap over its three runs: coverage 0.743
  Bootstrap over whole runs              covers these-tasks difference 0.811   tasks-like-these difference 0.595   median width 0.080
  t-interval over whole runs             covers these-tasks difference 0.963   tasks-like-these difference 0.867   median width 0.166
  Binomial, runs independent             covers these-tasks difference 0.994   tasks-like-these difference 0.909   median width 0.147
  Task-level, these tasks                covers these-tasks difference 0.948   tasks-like-these difference 0.760   median width 0.104
  Task-level paired, tasks like these    covers these-tasks difference 0.998   tasks-like-these difference 0.950   median width 0.169
  with  5 runs per task: bootstrap over whole runs covers the these-tasks difference 0.890 (one model's mean 0.842); task-level these-tasks interval 0.960
  with 10 runs per task: bootstrap over whole runs covers the these-tasks difference 0.925 (one model's mean 0.897); task-level these-tasks interval 0.950
  with 20 runs per task: bootstrap over whole runs covers the these-tasks difference 0.942 (one model's mean 0.939); task-level these-tasks interval 0.958
