# Spurious regression, unit roots, and cointegration

This is the self-contained, reproducible companion to the long-form Medium essay
**[A High R² Is Not a Long-Run Relationship](article.md)**.

It illustrates, using **synthetic Gaussian data only**, why independent random
walks can produce apparently significant conventional levels regressions; why
unit-root and estimated-residual cointegration tests require different null
distributions; what a genuinely stationary cointegrating residual and
error-correction mechanism look like; and how a structural break can invalidate
a single stable long-run relation.

## Requirements and commands

Run with Python 3.12+:

```bash
cd spurious-regression-cointegration
python -m pip install -r requirements.txt
python analysis.py
python -m unittest discover -s tests -v
```

The full experiment is seeded (`20261031`) and takes a few minutes on a laptop.
It writes eight PNGs to `figures/` and fifteen CSVs to `results/`.

For a faster test with *separate filenames* that cannot overwrite full outputs:

```bash
python analysis.py --quick
```

Use `--output PATH` to change the output root. All files are plain text CSV or
PNG; no API key, external dataset, paid service, or online dependency is used
after installing the packages. The notebook
[`spurious_regression_cointegration.ipynb`](spurious_regression_cointegration.ipynb)
walks through the logic and executes sample diagnostics from a fresh kernel.

## Design and scope

| Experiment | Full repetitions | Quick repetitions | Main object |
| --- | ---: | ---: | --- |
| Independent random-walk, difference and IID regressions | 1,400 each | 90 each | Invalid conventional t-test and R² comparison |
| DF on observed level and EG on estimated residual nulls | 1,800 each | 150 each | **Separate** design-specific finite-sample lower 5% quantiles |
| Long-run slope scaling, at 100/200/400/800 observations | 260 per length and system | 60 per length and system | Median absolute long-run slope errors |
| Known slope break at index 252 of 420 | 300 | 65 | Pooled versus regime-specific slope behaviour |

The no-cointegration null consists of two independent Gaussian random walks
of 250 observations. The calibrated DF test has an intercept and no lagged
differences. The calibrated EG test estimates a first-stage OLS levels
regression **with** an intercept and applies a residual difference regression
**without** an intercept, again with zero augmented lags. The resulting
critical values are **not universal ADF or Engle–Granger tables**. In
particular, they do not cover trends, serially dependent increments, lag
selection, or unknown structural breaks.

The true cointegration example uses `X = cumsum(N(0,1))`, `Y = 1.6 X + U`,
and `U_t = 0.65 U_(t−1) + ξ_t` for independent `ξ ~ N(0,0.7²)`.
Its exact error-correction coefficient is `0.65 - 1 = -0.35`. A later
example changes the equilibrium slope from 1.6 to 2.3 and demonstrates
instability without offering a formal calibrated structural-break test.

The first figure's random-walk pair is **selected for illustration**:
the naïve conventional p-value must be smaller than `1e-5` and the sample
R² larger than 0.25. The number of attempts appears in
`results/illustrative_null_path.csv`. This selection is fully excluded from
all Monte Carlo false-rejection estimates.

## Verification and limits

The unittest suite tests the generating identities, coefficient calculations,
stationarity implications, DF/EG implementation, error-correction identity,
seed reproducibility, input validation, CSV schemas, notebook execution, and
eight-figure/15-table output completeness. GitHub Actions runs it in a clean
Python 3.12 environment and regenerates quick outputs.

The study is a teaching and verification experiment. **Neither cointegration
nor short-run predictive association establishes a causal effect.** Empirical
unit-root and residual testing require a justified specification, correct
critical values, stability diagnostics, and, for causal claims, independent
identification assumptions.
