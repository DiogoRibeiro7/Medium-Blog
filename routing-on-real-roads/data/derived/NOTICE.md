# Licence of the derived tables

The tables in this directory (`points.csv`, `days.csv`, the distance matrices
`*_road.csv` and `*_straight.csv`, and `manifest.json`) are a database derived from
OpenStreetMap data, and so is `../../results/solves.csv`, which is computed from them.

Map data © OpenStreetMap contributors, available under the Open Database Licence (ODbL),
from Geofabrik's extract `portugal-261027.osm.pbf`: https://www.openstreetmap.org/copyright.
These derived tables are published under the ODbL, not under the repository's Apache-2.0
licence, which covers the code.
