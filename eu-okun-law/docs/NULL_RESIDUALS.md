# Null-imposed bootstraps with errors from the unrestricted residuals

Generated by `eu-okun null-residuals`. **Post hoc, not registered.** An external review (2026-10-20) pointed out that the registered null-imposed bootstraps fit their error process to the restricted residuals. Those residuals absorb the omitted, persistent GDP effect, so the bootstrap and the size study simulate a null whose errors are more persistent than the data's. This run keeps the null on the mean and takes the error process from the unrestricted residuals. Everything else is registered: data, designs, statistics, draws, seeds and size-study settings. Benjamini-Hochberg (BH) adjustments, which control the false discovery rate, are added next to the registered Holm adjustments, which control the chance of any false rejection. Nothing here replaces a registered result.

## Reading

- Restricted residuals are the usual choice for a null-imposed bootstrap, but when the omitted effect is persistent they make the null process too persistent. That lowers power for large sums and exaggerates the size distortion of the normal reference: 22.0% against 16.6% for the headline sums.
- On the less persistent null, the registered sieve bootstrap holds its size (5.1%), and the variant with unrestricted errors over-rejects (8.0%). A count that rests on a test that over-rejects is not a valid replacement for the registered count.
- Holm controls the chance of any false rejection among the countries. BH controls the expected share of false rejections among those declared, which is the question of how many countries have a negative sum. On the registered p-values BH gives 19 countries (19 with unrestricted errors). BH is guaranteed for independent tests and for positively dependent one-sided tests; these are two-sided and dependent through common shocks. Benjamini-Yekutieli (BY), valid under any dependence, gives 1 (7).
